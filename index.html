What Is Web Accessibility?

Web accessibility means designing and building websites so that all people — including those with visual, auditory, motor, or cognitive disabilities — can perceive, understand, navigate, and interact with them.

CSS plays a surprisingly large role. From readable font sizes to focus indicators to motion preferences, the styles you write directly affect whether someone can use your site.

💡

The WCAG (Web Content Accessibility Guidelines) defines three conformance levels — A, AA, and AAA — with AA being the standard most organisations aim for.

Focus Styles — Don't Remove Them

One of the most common accessibility mistakes is removing the default focus outline with outline: none without providing a replacement. Keyboard users depend on visible focus to navigate.

/* ❌ Don't do this */
:focus { outline: none; }

/* ✅ Do this instead */
:focus-visible {
  outline: 3px solid #6ee7b7;
  outline-offset: 3px;
  border-radius: 4px;
}

:focus-visible only shows the ring for keyboard navigation — mouse users won't see it, which is the best of both worlds.

The Visually Hidden Technique

This classic CSS pattern hides content from sighted users while keeping it fully accessible to screen readers:

.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
03

Color & Contrast

WCAG 2.1 requires a minimum contrast ratio of 4.5:1 for normal text and 3:1 for large text (18pt or 14pt bold) at the AA level.

Level Normal Text Large Text UI Components
A No requirement No requirement No requirement
AA 4.5 : 1 3 : 1 3 : 1
AAA 7 : 1 4.5 : 1 No requirement

CSS custom properties make it easy to maintain a colour system that meets these ratios:

:root {
  /* Text colours — each tested against background */
  --text-primary:  #e2e8f0; /* 12:1 on dark bg */
  --text-muted:    #8898b3; /* 4.6:1 on dark bg */
  --accent:        #6ee7b7; /* 8.5:1 on dark bg */
}
🛠️

Never use colour alone to convey meaning. Always pair colour cues with text, icons, or patterns — for users who are colour blind.

04

Motion & Animation

Animations can cause problems for people with vestibular disorders, epilepsy, or motion sensitivity. CSS provides a media query to respect user preferences:

/* Default: animations enabled */
.card {
  transition: transform 0.3s ease, opacity 0.3s ease;
}

/* Respect user's reduced-motion preference */
@media (prefers-reduced-motion: reduce) {
  .card {
    transition: none;
  }

  /* Or keep subtle opacity but remove transforms */
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
  }
}
  • ✓ Use prefers-reduced-motion for all non-essential animations.
  • ✓ Avoid content that flashes more than 3 times per second.
  • ✓ Provide pause/stop controls for auto-playing content.
  • ✓ Parallax effects should be treated as motion and guarded.
